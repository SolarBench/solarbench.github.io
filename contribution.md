# Contribute to SolarBench

## Dataset contribution

We welcome dataset contributions to SolarBench. If you would like to contribute data, please contact Yuhao Nie at [nieyh@mit.edu](mailto:nieyh@mit.edu).

To make the contribution process as smooth as possible, we kindly ask you to prepare a brief README describing your dataset, including:

- **Data collection:** Where and how the data were collected, including site locations, instruments, and sensors.
- **Data specifications:** Temporal coverage, temporal and spatial resolution, available data modalities, and file formats.
- **Processing and quality control:** Any preprocessing, corrections, filtering, calibration, or quality-control procedures applied to the data.

## Python library contribution

We welcome contributions to the SolarBench Python library. To propose improvements, bug fixes, or new features, please create a branch, make your changes, and submit a pull request to our <a href="https://github.com/Solar4cast/solarbench" target="_blank" rel="noopener noreferrer">GitHub repository</a> for review.
