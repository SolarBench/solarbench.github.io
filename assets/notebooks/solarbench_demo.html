Dataset meta information retrieval¶

The DatasetsInfo class allows you to retrieve the meta information for the datasets that you are interested in. You can query the information either by dataset names (DatasetsInfo.by_name) or by dataset features (GetDatasetsInfo.by_features).

Evaluating your Model¶

Provided are various functions for evaluation of a model's performance.

These include:

  • Mean Absolute Error (MAE)
  • Root Mean Squared Error (RMSE)
  • Mean Bias Error (MBE)
  • Relative RMSE (RRMSE)
  • Temporal Distortion Index (TDI)
  • Temporal Distortion Mix (TDM)

See Barhmi et. al. (2024) (https://www.mdpi.com/2673-9941/4/1/5) for more details.
